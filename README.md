# TradeLive — Landing Page

A three-page static site for a trading app concept ("¡Hola trader!"), in Spanish, built in 2022.

**Live:** [tradelive-bdlc.vercel.app](https://tradelive-bdlc.vercel.app/)

## What's in it

- `index.html`: hero and features section.
- `aboutus.html`: vision and mission.
- `contactme.html`: contact form ("Escríbenos").
- CSS organized in layers: design tokens (`variables.css`), utilities, base styles and one stylesheet per page.

Desktop layout; plain HTML and CSS, no build step.
